# tieba-archiver

> 把贴吧帖子变成本地 Markdown，带图，防丢。

```
 _____ _      _              _             _     _
|_   _(_) ___| |__   __ _   / \   _ __ ___| |__ (_)_   _____ _ __
  | | | |/ _ \ '_ \ / _` | / _ \ | '__/ __| '_ \| \ \ / / _ \ '__|
  | | | |  __/ |_) | (_| |/ ___ \| | | (__| | | | |\ V /  __/ |
  |_| |_|\___|_.__/ \__,_/_/   \_\_|  \___|_| |_|_| \_/ \___|_|
```

基于 DrissionPage + BeautifulSoup 的贴吧帖子归档工具。抓取帖子正文 + 高清原图，输出为 Markdown 文件。

> [!IMPORTANT]
> 贴吧 PC 帖子页已经改为 Vue 动态渲染。当前 `tieba.py` 中基于 `.l_post` / `.d_post_content` 的旧版解析逻辑不能完整处理新版页面，尤其会漏掉楼中楼和 `.image-card-wrapper` 中的图片。新版页面的完整实测方法、选择器、楼中楼分页接口、图片本地化和校验流程见 [贴吧新版完整归档实现记录](docs/modern-tieba-full-archive.md)。

---

## 安装

```bash
pip install -r requirements.txt
```

依赖：`DrissionPage`（浏览器自动化）、`beautifulsoup4`（HTML 解析）。

---

## 运行模式

### 模式 1：接管模式（Takeover）

劫持你已经登录的 Chrome 会话。适用于需要登录才能查看的内容。

**步骤：**

```bash
# 1. 启动带调试端口的 Chrome
chrome.exe --remote-debugging-port=9222

# 2. 在该浏览器中登录你的百度账号

# 3. 运行脚本，选择模式 1
python tieba.py
```

### 模式 2：独立模式（Standalone）

自动拉起一个全新的浏览器实例，零配置。适用于公开帖子。

```bash
python tieba.py
# 选择模式 2
```

## 使用

运行后进入交互式命令行，粘贴链接即可：

```
[启动模式]
  1. 接管模式 — 连接已打开的 Chrome (需先启动带调试端口的 Chrome)
  2. 独立模式 — 自动启动新浏览器实例

请选择 [1/2] (默认 1): 1
>>> 接管成功！当前页面: 百度一下

==================================================
  贴吧帖子归档工具 | Tieba Archiver
  输入帖子链接开始下载，输入 q 退出
==================================================

>>> https://tieba.baidu.com/p/5875924070

--- 正在归档: 某某帖子标题 ---
   读取第 1 页... [识别到共 3 页]  √
   读取第 2 页... √
   读取第 3 页... √
   [√] 某某帖子标题.md 完成

>>> 5875924070
--- 正在归档: ...

>>> q
再见。
```

支持两种输入格式：
- **完整链接**：`https://tieba.baidu.com/p/1234567890`
- **纯数字 ID**：`1234567890`

## 输出

```
Downloads/
├── assets/              # 高清原图
│   ├── abc123.jpg
│   └── ...
├── 帖子标题A.md
├── 帖子标题B.md
└── ...
```

Markdown 文件包含：帖子标题、原始链接、各楼层正文、内嵌图片引用。

## 机制

| 特性 | 说明 |
|------|------|
| 断点续传 | 已下载的帖子（文件 > 100 字节）自动跳过 |
| 只看楼主 | 默认 `see_lz=1`，只抓楼主发言 |
| 防重复 | 基于 post_id 指纹去重，防止百度重定向回第一页 |
| 验证码 | 遇到百度安全验证时暂停，等你手动搞定 |
| 高清图 | 从 `imgsrc.baidu.com` 拉原图，非缩略图 |
| 限速 | 每页间隔 2~3 秒随机延迟 |

## 完整 HTML 存档校验

仓库提供一个不依赖第三方库的校验工具，用于检查主楼层、楼中楼和本地图片引用：

```bash
python tools/verify_archive.py "帖子（全部楼层）.html" \
  --expected-main 566 \
  --expected-nested 1249 \
  --expected-assets 220
```

真实帖子正文、楼中楼数据和图片默认不应提交到公共仓库；`.gitignore` 已排除生成的 HTML、资源目录和抓取中间状态。
